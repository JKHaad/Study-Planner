Data Management

Add to Home Screen

This planner is one self-contained file and works fully offline.
Android (Chrome): open the file in Chrome, tap ⋮ → Add to Home screen. This pins a shortcut to the file where it is stored, so don't move or delete it.
iPhone / iPad: iOS can't pin a local file to the home screen. Open the file from a link instead (any free web host, or a link you send them), then Share ⬆ → Add to Home Screen.
Use Save progress into HTML file regularly: that copy contains the student's data.
